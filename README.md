# Demo - Introduction to Agentic AI
This repository contains a demo and exercises for the lecture "Introduction to Agentic AI" at the HAW Hamburg.

## Student Exercise

Students should keep the architecture and replace the domain:

- Edit `model/llm.py` to define a new agent persona and behavior.
- Add or modify tools in `tools/`.
- Replace or extend the knowledge source in `knowledge/crawler.py`.
- Run `make run-fresh` to rebuild the corpus and vector database.

Good exercise target: create an agent for a different university service, conference website, course FAQ, or public office website.
